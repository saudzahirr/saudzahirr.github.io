# Projects

## Power Systems and GNN-based Modeling

My MS thesis explores the use of Graph Neural Networks (GNNs) for simulating dynamic power flows in large-scale electric grids. The aim is to develop more efficient and scalable methods than traditional numerical solvers for real-time grid management.

### Key tools
* Python (PyTorch, PyTorch Geometric)
* Power system modeling with MATLAB & Simulink
* Integration with real-world datasets

## deltaFlow: Power Flow Solver

`deltaFlow` is a C++/FORTRAN based tool for steady-state power flow simulations. It aims to be fast and adaptable for academic simulations and grid design planning.

* GitHub: [deltaFlow](https://github.com/saudzahirr/deltaFlow)

## Battery End-of-Life Prediction

A machine learning pipeline built on GPR (Gaussian Process Regression) for predicting battery degradation. The system uses ESP32 and ThingSpeak for data acquisition and logging.

* Hardware: ESP32, IoT cloud integration
* Tools: Python, ThingSpeak, GPR models
